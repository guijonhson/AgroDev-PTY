# AgroDev PTY — Sitio web corporativo

Sitio web corporativo construido únicamente con HTML5, CSS3 y JavaScript vanilla.

## Estructura

- `index.html` — estructura y contenido de la página.
- `css/styles.css` — estilos, responsive design y componentes visuales.
- `js/script.js` — menú móvil, año automático, formulario y portal próximamente.

## Ejecutar

Abre `index.html` directamente en el navegador o utiliza Live Server en Visual Studio Code.

## Próximas integraciones recomendadas

1. Conectar el formulario a un backend o servicio de correo.
2. Sustituir los datos de contacto de ejemplo por los datos oficiales.
3. Crear un favicon y logotipo oficial.
4. Añadir fotografías reales de proyectos, agricultura y tecnología.
5. Crear una página/login para clientes.
6. Incorporar SEO técnico y analítica.
7. Conectar futuras plataformas SaaS de AgroDev PTY.
