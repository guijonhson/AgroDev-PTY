# AgroDev PTY — Sitio web corporativo

Sitio web corporativo construido únicamente con HTML5, CSS3 y JavaScript vanilla.

## Estructura

- `index.html` — estructura y contenido de la página.
- `css/styles.css` — estilos, responsive design y componentes visuales.
- `js/script.js` — menú móvil, año automático, formulario y portal próximamente.

## Ejecutar

Abre `index.html` directamente en el navegador.
